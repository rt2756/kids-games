# Little Learners Games

Free learning games for children aged 1 to 10 — counting, letters, colours,
shapes, logic puzzles and more. They run in any web browser on a phone,
tablet or computer, need no sign-up, show no ads and collect no data.

**Play:** https://rt2756.github.io/kids-games/

Tip: use "Add to Home Screen" and the games keep working offline.
